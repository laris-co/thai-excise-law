# MCP QA — 10 topics x 10 rounds (2026-11-21)

Ten agents each asked 10 member-style questions on one topic through the `craft-beer-excise` MCP
(`ask_law` + `search_law` hybrid k=5) and checked the numbers against the original PDF pages.
An 11th agent probed the tool surface itself. Backend: `proto/server.py` with reranker, gate 0.5.

About 24 of 100 rounds fully right. English and mixed Thai-English questions were refused in every topic.

## Root causes (ordered by how many rounds they broke)

1. **OCR drops Thai single digits, so section labels break.** "ข้อ ๕" becomes "ข" / "ขอ" / "ข้", so the
   splitter labels sections "ถัดจากข้อ 3", folds ข้อ 10-11 into ข้อ 9, and loses ข้อ 15 entirely.
   Numbers in tables drop too: "ประเภทที่ ๓", "มาตรา ๕", "๑,๐๐๐", the % column, "4300" for ๔๓๐.
2. **No document status beyond `cancelled`.** Superseded fee schedules, a 2023-only exemption,
   a rule effective 2027-02-01 and regulations repealed by 9454_7251 / 9466_7248 all show "ใช้บังคับ".
3. **No scope fields.** Nothing says beer vs non-beer, commercial vs not-for-sale, domestic vs import,
   or Act ceiling vs actual rate, so the reranker happily matches the wrong category.
4. **Query side.** English, slang (ไลเซ่น, บริวผับ, แบบ2), typos (เบีย, เบียบ) are not expanded;
   "กินเอง" maps to homebrew even for personal import.
5. **Gate is binary.** 0.46-0.48 hits that hold the answer are refused; off-topic 0.85-0.88 hits
   (Japan fees, ภ.ง.ด.50, มหาดไทย tax) are answered.
6. **Duplicates fill the 3 answer slots.** 5790_6542/5790_6465, 7601_4726/7601_4728,
   5754_2614/5754_3008, 7595_4946/7595_4693.
7. **Wrong PDF.** `5790_6542` OCR has 112 pages, its local PDF has 20 and stops at มาตรา 112.

## Features asked for (merged from all 11 reports)

**Data (fix first, everything else depends on it)**
- Splitter accepts OCR forms "ข N" / "ขอ N" / "ข้ N" as ข้อ; label from the heading inside the chunk.
- `status`: in_force / superseded / not_yet / time_limited, with `superseded_by` and `amended_by`
  parsed from "ให้ยกเลิก" / "ให้ใช้ความต่อไปนี้แทน" clauses; drop non-in-force from `ask_law`.
- `applies_to`: beer / non_beer / spirits, commercial / non_commercial, domestic / import;
  `role: ceiling` on the Act's fee and rate tables.
- Collapse duplicate doc keys; check PDF page count against OCR page count corpus-wide.
- Flag numbers OCR may have lost (empty "ประเภทที่", "มาตรา วรรค", a bare "ข") so answers say "check PDF".

**Retrieval and answer**
- English-to-Thai and slang/typo expansion; fix the กินเอง mapping.
- Near-miss band (0.40-0.50): answer marked low-confidence with the nearest clause, not a flat refusal.
- Scope check: refuse with a reason when the topic is another law (Alcohol Control Act, Revenue Code)
  or a key term has no documents.
- `best_span` = whole numbered item, never cut before the number; `search_law` returns it too.
- Answer slots from different documents; rank operative clauses above annex forms.
- Attach the ข้อ 2 definitions when a question is about volume / giving / exchanging.

**MCP tools and fields**
- `get_section(doc_key, "ข้อ 39" | "มาตรา 155")`.
- `page_image(doc_key, page)` / `verify_page` — OCR text beside the page image.
- `rate_lookup(item)` and `fee_lookup(licence)` — current value, regulation, previous value.
- `doc_relations(doc_key)` — amends / cancels / amended by.
- Citations carry `pdf_page` and the printed Gazette page (เล่ม / ตอน / หน้า) as fields.
- `pdf_local#page=N` in every `markdown` block; `read_ocr` returns markdown, warns on bad ranges,
  lists only the sections on the requested pages.
- `search_law` notes when k was clamped and caps total text; `ask_law` passes HTTP 400 through
  instead of "server not reachable".
